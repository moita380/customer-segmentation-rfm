# Customer Segmentation - RFM Analysis

## Overview
Customer segmentation project using RFM (Recency, Frequency, Monetary) analysis on Online Retail data.

## Tools
- Python (Pandas, Seaborn, Matplotlib)
- MySQL
- Excel
- Jupyter Notebook

## Segments
- Champions
- Loyal Customers
- Potential Loyalists
- New Customers
- At Risk
- Need Attention
- Lost
